# rps-tyranny

You are forced to play rock-paper-scissors against this page: win (you probably won't) and it confesses one of the author's embarrassing quirks; lose and you get kicked out; lose three in a row and you're banned. Forever.

## Run

`python server.py` - zero dependencies, pure stdlib - then open `http://localhost:8000`. Set the `RPS_QUIRK_TOKEN` environment variable if you (the author) want to submit quirks remotely.
